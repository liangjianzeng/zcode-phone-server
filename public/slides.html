接入层 → 六大功能模块 → 引擎与数据

零 npm 依赖，Node ≥22.5（node:sqlite）；只监听 127.0.0.1，手机经 SSH 隧道接入。

模块设计 · 流式与跟随06

双通道跟随 · 唯一事实来源

服务端 delta 合帧

相邻同键 token chunk 60ms 合并成一帧，严格 FIFO 不重排：长回复 SSE 帧量从数千降到数十，蜂窝网络省流量、渲染不碎片。

模块设计 · 运行态状态机07

任何运行态都必须能退出

配套：turn.failed 给人话提示（1113/429 分流）、自动重试、回合结束分隔线与当轮产出卡。

模块设计 · 改动红线08

桥接契约——App 功能靠它们活着

运行哨兵词

[role=status][aria-live=polite] 含 Deep diving，仅运行时存在于 DOM——常驻 = App 永远"任务进行中"。

成果 chip

.fileMention + title=完整路径；页面侧不得 stopPropagation（桥在 document 冒泡阶段接管，按后缀分流查看器/下载）。

审批与输入

权限卡片按钮短文案 批准 / 拒绝（≤12 字正则识别）；原生 textarea#composer + data-composer-card 放行注入区。

两代 App 桥并存

v2 通知（onTaskState）与 DOM 哨兵双通道，通知 id 相同自然去重；APK 全量升级后可撤哨兵兼容。

回归红线：改页面先核对 MODULE-DESIGN §3.7；改 boot 核对 busy > lastSession > 最近 的优先级顺序。
