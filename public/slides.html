  • 与桌面共用同一引擎：手机派的任务由电脑上的 ZCode 引擎执行，家用它跑
  • 免登录：共享桌面凭据（start-plan JWT 直通），装上就能用
  • 同一批会话：手机和桌面互相旁观任务进度，部件级实时跟随

技术底座 · 凭什么流畅可靠06 / 09

卖点背后，全是硬活

四个自研关键机制

🔄 双通道实时跟随

桌面跑的任务手机实时看见——SSE 事件流 + 1.2s 存储轮询双保险，部件级唯一事实来源，杜绝重复渲染。

part.upserted/delta + renderTail · 未变化零重绘

🚄 流式不卡不费

长回复上万 token 也流畅：相邻同键 chunk 合并成一帧，蜂窝网络省流量。

60ms delta 合帧 · 严格 FIFO · SSE 帧量数千→数十

🩺 运行态必收敛

断流、重启、取消都不会"永久转圈"——四条收敛路径以共享存储为准自愈。

4 置位 + 4 收敛 · 45s 兜底复位

🧬 自研底层

隧道吞吐被本地 fork 撑起来的：认证后 zlib 压缩 + 整包批量解密；服务端零 npm 依赖。

dartssh2 fork · Node ≥22.5 · 21 条踩坑档案全修复
安全与隐私07 / 09

你的话、你的码，不出你的机器

隐私不是设置项，是架构

🎙️ 语音完全离线

160MB 流式模型在手机本地推理，语音永不上传云端。

🔐 加密隧道 + 防中间人

SSH 加密回环隧道不经公网；主机密钥 TOFU 校验，换机/重装立刻告警。

🗄️ 敏感信息加密

密码/私钥存 Android Keystore；服务端只监听 127.0.0.1，永不暴露公网。

📥 产出直读不中转

成果经 SSH(SFTP) 从你的电脑直读手机，没有第三方云盘经手。

token 鉴权（≥16 位自动生成）· config/日志均已 gitignore，不入仓库
